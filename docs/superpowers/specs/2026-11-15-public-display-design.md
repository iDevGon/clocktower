# 이야기꾼 PC 공용 화면

사용자가 별도 창 방식과 참가 인원 기준 기본 분배를 선택했다.

- PC 웹의 대기실과 진행 화면에서 공용 창을 열고, 재클릭하면 기존 창에 포커스한다.
- 좌석 순서, 공개된 생존/유령표 상태, 날짜/단계, 타이머, 지명/확정 투표/처형 후보를 실시간 표시한다.
- 밤에는 직전 공개 상태를 유지한다. 밤 도중 처음 접속해서 직전 상태를 모르면 아침까지 생존 상태를 표시하지 않는다.
- 일반 참가자 수 기준 기본 분배를 표시한다. 여행자는 별도로 집계하며 역할에 따른 구성 변동은 반영하지 않는다.
- 설정의 에디션·제외·추가 직업에 따라 등장 가능한 모든 직업과 기존 능력 설명을 진영별로 표시한다. 실제 배정 여부를 구분하지 않는다.
- 비공개 역할/진영, 표식, 메모, 채팅, 밤 행동, 블러프, 사전 투표 선택은 전달하지 않는다.
- 공용 창은 별도 서버 연결 없이 이야기꾼 창이 전달하는 공개 데이터만 렌더링한다. 전체 화면 버튼과 연결 상태를 제공한다.
- 공용 창에는 페이지 및 내부 스크롤을 두지 않는다. 좌측 좌석/진행 정보와 우측 2열 직업 설명을 하나의 보드로 배치하고, 실제 전체 콘텐츠 크기로 축척을 계산해 창 안에 모두 표시한다. 창 크기, 전체 화면, 직업 목록 변경 시 재계산한다.
- 프로젝터 가독성을 위해 양피지색 바탕·크림색 직업 목록·짙은 남색 상단으로 구분하고, 진한 잉크색 글자와 절제된 황동색 테두리를 사용한다. 큰 글자와 높은 대비를 유지한다. 표준 직업은 핵심 능력을 짧게 요약하고 원문은 설명의 툴팁으로 보존한다. 요약이 없는 직업은 원문을 표시한다. 사망한 플레이어도 이름은 진하게 유지하며 사망 문구·점선·배경으로 구분한다.
- 좌석·기본 분배·투표 현황을 각각 패널로 나누고, 직업 목록은 진영별 색상 패널 안에서 이름과 설명을 열로 구분한다. 마을주민은 파랑, 외지인은 청록, 하수인은 주황, 악마는 적색, 여행자는 보라로 통일한다.
- 기본 인원 분배에는 누적 막대그래프와 숫자 범례를 함께 표시한다. 좌석 중앙에는 공개된 생존/사망 비율을 도넛 그래프로 표시한다. 이전 공개 상태를 알 수 없는 밤에는 도넛을 표시하지 않는다.
- 부모 창 종료 시 공용 창을 닫고 구독과 타이머를 해제한다. 팝업 차단은 안내한다.

검증: 공개 데이터 투영과 HTML 이스케이프 단위 테스트, 이야기꾼 테스트/타입 검사, 변경 파일 Biome 검사, 웹 export 및 브라우저 확인.
