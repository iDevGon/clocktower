# React 기초

## 컴포넌트와 JSX

- React 컴포넌트는 UI를 반환하는 JavaScript 함수(또는 클래스)
- JSX는 JavaScript 안에서 HTML과 유사한 마크업을 작성할 수 있게 해주는 문법 확장
- JSX는 빌드 타임에 `React.createElement()` 호출로 변환됨
- 컴포넌트 이름은 반드시 대문자로 시작해야 함 (PascalCase)
- JSX에서 JavaScript 표현식은 `{}`로 감싸서 사용

## Props

- Props는 부모에서 자식으로 데이터를 전달하는 읽기 전용 객체
- Props는 불변(immutable) — 자식 컴포넌트에서 수정 불가
- `children`은 특별한 prop으로 컴포넌트 태그 사이의 내용을 전달
- Destructuring으로 props를 받는 것이 일반적: `function Button({ label, onClick })`
- Default props: `function Button({ size = 'medium' })`

## State와 useState

- State는 컴포넌트 내부에서 관리하는 변경 가능한 데이터
- `useState`는 [현재값, setter함수] 튜플을 반환
- State 업데이트는 비동기적으로 배치(batch) 처리됨
- 이전 state에 기반한 업데이트는 함수형 업데이트 사용: `setCount(prev => prev + 1)`
- State가 변경되면 컴포넌트가 리렌더링됨

## 이벤트 처리

- React 이벤트는 camelCase: `onClick`, `onChange`, `onSubmit`
- 이벤트 핸들러에 함수 참조를 전달 (호출 X): `onClick={handleClick}` (O) vs `onClick={handleClick()}` (X)
- 합성 이벤트(SyntheticEvent): 브라우저 간 호환성을 위한 래퍼

## 조건부 렌더링

- 삼항 연산자: `{isLogged ? <Dashboard /> : <Login />}`
- 논리 AND: `{isAdmin && <AdminPanel />}`
- Early return: 조건에 따라 컴포넌트 초반에 다른 JSX 반환

## 리스트 렌더링

- `map()`으로 배열을 JSX 요소 배열로 변환
- 각 요소에 고유한 `key` prop 필수 — React의 재조정(reconciliation) 성능 최적화에 사용
- `key`로 배열 인덱스 사용은 지양 (순서가 변할 수 있는 경우)
- `key`는 형제 요소 간에만 고유하면 됨 (전역 고유 아님)
