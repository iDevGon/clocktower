# React Native 기초

## React Native란

- React를 사용하여 iOS/Android 네이티브 앱을 개발하는 프레임워크
- 웹의 DOM 대신 네이티브 UI 컴포넌트로 렌더링됨 (UIView, android.view 등)
- JavaScript 스레드와 네이티브 스레드가 브릿지(또는 새 아키텍처의 JSI)를 통해 통신
- "Learn once, write anywhere" — 웹과 코드를 공유하되, 플랫폼별 최적화 가능

## 핵심 컴포넌트

- `View` — `<div>`에 대응. 레이아웃 컨테이너. 기본 flexbox 레이아웃
- `Text` — 텍스트 표시. 모든 텍스트는 반드시 `<Text>` 안에 위치해야 함
- `Image` — 이미지 표시. `source` prop으로 로컬/원격 이미지 지정
- `ScrollView` — 스크롤 가능한 컨테이너. 내용이 적을 때 사용
- `FlatList` — 큰 리스트를 효율적으로 렌더링. 가상화(virtualization) 기본 적용
- `TextInput` — 텍스트 입력 필드
- `TouchableOpacity` / `Pressable` — 터치 가능한 래퍼

## 스타일링

- `StyleSheet.create()`로 스타일 객체 생성 (성능 최적화)
- CSS와 유사하지만 camelCase 사용: `backgroundColor`, `fontSize`
- 모든 치수는 기본적으로 dp(density-independent pixels) 단위
- Flexbox가 기본 레이아웃 — `flexDirection` 기본값이 **`column`** (웹은 `row`)
- 인라인 스타일도 가능하나 `StyleSheet`이 권장됨

## Flexbox (React Native)

- `flexDirection`: 기본값 `column` (위→아래)
- `justifyContent`: 주축(main axis) 정렬
- `alignItems`: 교차축(cross axis) 정렬
- `flex: 1` — 사용 가능한 공간 전체 차지
- `gap` — 자식 요소 간 간격 (최신 RN 지원)

## FlatList vs ScrollView

- **ScrollView**: 모든 자식을 한번에 렌더링. 항목이 적을 때 적합
- **FlatList**: 화면에 보이는 항목만 렌더링(가상화). 큰 리스트에 필수
  - `data`: 배열 데이터
  - `renderItem`: 각 항목 렌더링 함수
  - `keyExtractor`: 고유 키 추출 함수
  - `onEndReached`: 끝에 도달 시 콜백 (무한 스크롤)

## 플랫폼별 코드

- `Platform.OS` — `'ios'` | `'android'` | `'web'`
- `Platform.select({ ios: ..., android: ..., default: ... })`
- 파일 확장자 분기: `Component.ios.tsx`, `Component.android.tsx`
