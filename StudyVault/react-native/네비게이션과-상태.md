# React Native 네비게이션과 상태관리

## Expo Router

- 파일 기반 라우팅 — `app/` 디렉토리의 파일 구조가 곧 라우트
- `app/index.tsx` → `/` 경로
- `app/game/lobby.tsx` → `/game/lobby` 경로
- `app/_layout.tsx` — 레이아웃 파일로 네비게이션 구조 정의
- Dynamic routes: `app/[id].tsx` → `/123` 매칭
- `useRouter()` — 프로그래밍 방식 내비게이션: `router.push()`, `router.replace()`, `router.back()`
- `useLocalSearchParams()` — URL 파라미터 접근
- `Stack`, `Tabs` 등 네비게이션 레이아웃 지원

## Zustand (상태관리)

- 경량 상태관리 라이브러리. Redux 대비 보일러플레이트 최소화
- `create()` 함수로 스토어 생성:
  ```typescript
  const useStore = create<State>((set, get) => ({
    count: 0,
    increment: () => set((state) => ({ count: state.count + 1 })),
  }));
  ```
- 셀렉터로 필요한 상태만 구독 — 불필요한 리렌더링 방지:
  ```typescript
  const count = useStore((s) => s.count); // count가 바뀔 때만 리렌더링
  ```
- `get()`으로 액션 내에서 현재 상태 접근
- `set()`은 shallow merge — 부분 업데이트만 전달하면 됨
- 미들웨어: `persist` (AsyncStorage 영속화), `devtools`, `immer` 등

## AsyncStorage

- React Native용 비동기 키-값 저장소 (localStorage의 RN 버전)
- `await AsyncStorage.setItem('key', JSON.stringify(value))`
- `await AsyncStorage.getItem('key')` — 문자열 반환, JSON.parse 필요
- Zustand `persist` 미들웨어와 결합하여 스토어 자동 영속화

## Socket.io (클라이언트)

- 실시간 양방향 통신 라이브러리
- `io(url, options)` — 소켓 연결 생성
- 네임스페이스로 이벤트 채널 분리: `io('/player')`, `io('/storyteller')`
- `socket.emit(event, data)` — 서버로 이벤트 전송
- `socket.on(event, callback)` — 서버 이벤트 수신
- `socket.off(event, callback)` — 리스너 제거
- 자동 재연결, 연결 상태 관리 등 기본 제공
- TypeScript 타입 안전성: 제네릭으로 이벤트 타입 정의 가능

## React Native 애니메이션

### react-native-reanimated
- UI 스레드에서 직접 애니메이션 실행 — JS 스레드 블로킹 없음
- `useSharedValue` — 애니메이션 값 (JS와 UI 스레드 간 공유)
- `useAnimatedStyle` — 공유 값 기반 스타일 생성
- `withTiming`, `withSpring`, `withDecay` — 애니메이션 함수
- `Animated` 컴포넌트: `Animated.View`, `Animated.Text` 등

### react-native-gesture-handler
- 네이티브 제스처 시스템 활용
- `GestureDetector` + `Gesture.Pan()`, `Gesture.Tap()` 등
- reanimated와 결합하여 제스처 기반 애니메이션 구현
