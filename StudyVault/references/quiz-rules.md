# Quiz Rules

## 핵심 원칙

1. **힌트 절대 금지**: 선택지 라벨이나 설명에 정답을 암시하는 단서를 포함하지 않는다
2. **정답 위치 랜덤화**: 정답이 항상 같은 위치(A, B 등)에 오지 않도록 한다
3. **오답의 그럴듯함**: 오답은 초보자가 실제로 혼동할 수 있는 내용이어야 한다
4. **개념 단위 출제**: 각 문제는 하나의 명확한 개념을 테스트해야 한다

## 문제 작성 규칙

- 문제당 선택지 4개 (단일 정답)
- 선택지에 "(정답)", "(추천)" 등의 표시 금지
- "위의 모든 것", "해당 없음" 같은 선택지 지양
- 코드 스니펫을 포함할 경우 실행 가능한 코드여야 한다
- 개념의 **이해도**를 측정하는 문제 (단순 암기 X)

## 난이도 가이드

- **기초**: 정의, 기본 문법, 핵심 개념
- **중급**: 동작 원리, 비교, 패턴 적용
- **고급**: 엣지 케이스, 성능 트레이드오프, 내부 구현

## 오답 개념 재출제

기존에 틀렸던 개념(🔴)을 재출제할 때:
- 동일한 문제를 반복하지 않는다
- 같은 개념을 **다른 맥락**이나 **다른 각도**에서 묻는다
- 이전 오답 메모를 참고하여 혼동 지점을 정확히 공략한다
